## 📌 About ORKESTRIUM 2K26

**ORKESTRIUM 2K26** is the official technical symposium portal designed with a binge-worthy, cinema-grade **Netflix-inspired aesthetic**. Rather than a conventional college website, Orkestrium treats each technical competition as a high-stakes series episode—complete with billboard previews, genre tags, match ratings, episodic scheduling, and direct arena registrations.

---

## ⚡ Key Features

- **🍿 Netflix-Inspired Cinematic Interface**: Immersive dark mode UI (`#0e0e0e`), billboard trailer hero, genre badges, match percentage indicators, and custom cursor animations.
- **🎯 5 Original Arenas (Episodes)**: Detailed episode cards featuring rules, evaluation criteria, coordinator contacts, and direct registration links.
- **📅 Binge Schedule**: Timeline breakdown detailing every phase of the symposium from morning registration to the season finale awards.
- **⭐ Personalized "My List"**: Bookmark your favorite events and keep track of selected arenas in real time.
- **🗓️ Calendar Integration**: Add symposium events directly to Google Calendar or iCal.
- **📍 Route & Venue Guide**: Transit routes, bus schedules, suburban rail connections, and Google Maps integration for SRM VEC campus.
- **👥 Crew & Office Bearers Showcase**: Meet the organizers, faculty leads, and student coordinators.
- **🧈 Lenis Smooth Scrolling**: Kinetic, fluid page scrolling with micro-interactions powered by Framer Motion.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (or `yarn` / `pnpm`)

### 1. Clone the repository
```bash
git clone https://github.com/sanjay-n-01/ORKESTRIUM.git
cd ORKESTRIUM
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
